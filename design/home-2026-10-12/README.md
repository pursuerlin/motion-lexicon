# 首页构图探索 · 01

用户已选定第三版「图鉴展台」，深化版已应用到正式首页，资源版本 297。以下保留最初探索记录；当前实现、评审与验证见文末。

## 问题与任务

这是动效术语图鉴与交互工具。用户需要先看见效果，再找到名字、进入详情或复制表达。现有宽屏容器最大 1560px，但正文行宽与右侧灵感签各自有上限，导致中间出现较大的空带。应调整内容之间的关系，而不是在空白里添加无关装饰。

## 三个方向

| 方向 | 构图与记忆点 | 取舍 |
| --- | --- | --- |
| 01 紧凑编辑版 | 1160px 画布、40px 栏间距，保留纸感与衬线标题；用“口语 → 术语”入口承接左侧 | 改动最小，保留当前气质；手机引言占用更多高度 |
| 02 动效翻译台 | 通栏标题，下面横排描述、演示、术语；青瓷配色与无衬线标题 | 推荐方向：把产品用途变成可见的阅读路径，消除中央空带；较宽的演示需要选定后逐项适配 |
| 03 图鉴展台 | 短标题，一张主灵感签与两张真实交互作品；石墨底色和青色强调 | 动效优先、视觉吸引力强；同时展示三个作品，首屏密度和运行负担更高 |

保留随机抽取、重播、复制描述、查看术语、浏览图鉴和配方入口。手机改为纵向排列。三版都共用现有术语数据和演示引擎，开场统一为滚动抽帧播放，便于公平比较；新首屏文案以中文探索，尚未完成所有新文案的英文适配。

## C 版深化 · 版本 295

首屏任务是先试玩、再识别术语、进入详情或复制描述。标题收为「先看见，再说准。」；左右开放式展台分别承载拖拽擦除对比和七形态粒子球，中间是 25 种真实术语的随机灵感签。三个舞台顶边对齐，桌面灵感签固定 498px、手机固定 470px；手机优先主签，再展示两侧作品。重播、查看术语、配方和场景入口继续使用现有功能。

复用现有主题令牌、术语数据和演示引擎，不固定用户主题。新增文案支持中英文，缓动实验室默认收起。新实现位于 `assets/home-exhibit.css` 与 `assets/home-exhibit.js`。

网页本身的动效：首次出场轻微上浮与错峰（420ms、45ms 间隔）；抽签按钮反馈与结果入场（280ms）；从实际展台进入详情的共享舞台转场，返回焦点回到来源；链接箭头、场景下划线与按钮按压提供轻反馈。新增动效服从总开关及系统减少动态效果，两侧预览离屏、切到后台或打开详情时暂停。粒子球在关闭动效时仍可静态切换形状、拖动旋转，语言和主题变化也刷新 Canvas。

独立静态评审由 `exhibit_visual_review_295` 完成，评分 8.1/10。已按意见把术语名移到演示上方，说明降为辅助；形状按钮改为 12px 字号、36px 点击面积，独立排列下一形状；减少重复分隔与统计权重。保留「25 种精选动效」，因为它说明随机池的范围。剩余美学差距是两侧作品的吸引力仍不完全均衡；保持主灵感签的视觉优先级，未继续添加装饰。

减法：删除 C 的长引言、视觉区内重复提示、灵感签长定义和首屏重复分隔；保留对象名称、输入提示、当前形态与主操作。完整定义仍可在详情或复制内容中获取。

实际验证：1440×960、768px 平板、390×844 手机、320px 英文窄屏，无页面横向溢出；25 次抽签覆盖全部精选效果，无相邻重复，高度保持一致，并查看全池截图。最终复测连续抽签、三个详情入口与返回焦点、真实滑块拖拽（读数变为 77）、方向键、粒子形状开关及静态心形、内层滚动抽帧（帧号推进到 6）、重播复位、复制成功反馈。浏览器读取未取到系统剪贴板正文，因此复制内容未独立核对。纸感和石墨实际画面已查看。`python3 check.sh` 与 `git diff --check` 均通过。

## 页面交互深化 · 版本 296

延续用户选定的图鉴展台，把网页自身变成动效词典的实际用例。左右保留拖拽擦除对比、粒子球体变形；中间按实际展台 ID 排除这两件重复作品，剩余 23 种。保留其他点击和拖拽作品，避免把整个交互类别一并排除。新增玩法筛选「全部 / 滚动 / 指针 / 自动演绎」，分组为 4 / 10 / 9 种，每组使用不重复的随机袋，跨袋避免相邻重复。模式指示条滑动到选中项，结果标注真实输入方式。

抽取立即更新结果，360ms 揭示舞台和描述，520ms 签片反馈只发生在演示舞台内；快速再抽会中断并清理上一次反馈。首屏延续 420ms 错峰出场；阅读时分类高亮跟随、章节标题与卡片进入视口才显现、顶栏产生轻阴影，离开展台后出现「回到展台」。补充实验室展开、菜单弹出、搜索状态切换、复制成功与重播反馈；展台到详情继续复用共享元素转场。全部尊重动效开关和系统减少动态效果，不影响结果即时可用。演示内滚动不驱动页面阅读反馈。

触屏与窄屏指针效果改为轻点、滑动或点按条目的提示；跟随引擎补充 pointerdown 采样，不阻止原生纵向滚动。扇形卡片原有 click 展开、列表预览原有 click 选中复用。手机藏掉序列帧中重复的装饰文字；舞台缩为 228px，英文双行标题下 212px，主签固定 470px，桌面固定 498px。技术描述提高对比度。减法删掉两侧底部的两句重复介绍，保留术语、操作提示、当前形态和详情入口。

验证：完整随机袋 23 次覆盖 23 种、不含两侧固定作品；最终分组覆盖 4 / 10 / 9 种；连续抽取签片完成后残留数为 0；实际搜索「粒子球体」得到一项结果、清空恢复、分类可切换再取消。菜单、实验室、复制、重播、详情返回焦点与关闭动效操作通过。实际页面滚动使卡片按可见范围继续入场，分类底板跟随阅读，回展台入口出现。390×844 手机主签 470px，无横向溢出，扇形卡点击得到 open 状态；320px 英文无溢出，模式支持 Enter。系统触摸事件未在真手机硬件验证；本次窄屏交互使用浏览器点按，跟随输入另做源码核对。最终浏览器 console error 为空，python3 check.sh 和 git diff --check 通过。未验收 200% 浏览器缩放。
