# 翻页卷曲转场替换（v301）

用户指定 `/Users/linhuangjie/Documents/Codex/page-flip/翻书.html` 作为替换效果。

## 实现

- 保留原作品的 HER 图册、WebGL 纸张网格形变、柔和投影和松手弹簧算法。
- 术语卡片、详情和首页灵感签复用同一个实例工厂。
- 按用户要求删除底部整行控制栏（自动翻页、进度条、页码、箭头），画布占满原位置；保留拖动、画布左右点击、滚轮、方向键和 Home/End。
- 拖动采用原文件的嵌入式逻辑：纸张进度直接跟随指针；松手后才使用原刚度、阻尼和积分步长完成翻页或回弹。
- `heldShape` 直接复用原文件函数。半途反向时从当前卷曲开始，按拖动距离连续调整卷曲方向，避免用时间补间造成迟滞。
- 保留原文件的抓停、反向速度更新和取消手势处理。
- 图册仅在挂载时加载；隐藏或离屏暂停，销毁时取消动画帧、事件和观察器，释放 WebGL 上下文。
- 缓存画布尺寸和主题底色，尺寸或主题变化时刷新，避免翻页每帧读取布局和计算样式。
- 中英文操作提示与主题同步；关闭动效后松手直接切到整页。

## 验证

- `node tests/page-book.test.cjs`：真实实例和事件处理器配合确定性时钟，验证指针立即跟随、微小反向无突变、卷曲不会随时间漂移、松手回弹、中途抓停、取消手势、快速改向、关闭动效、无隐藏自动播放入口与控制栏依赖。测试使用 WebGL 桩，渲染画面另通过浏览器确认。
- 浏览器详情：控制栏节点为 0，画布填满舞台；正反拖拽、页码状态和运行日志正常。
- 浏览器首页与手机：共用相同可视化，不保留控制栏占位。
- `python3 check.sh` 和 `git diff --check` 通过。

需要浏览器支持 WebGL。素材来源记录见 `assets/page-book/NOTICE.md`；用户原始文件未修改。
